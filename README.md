Project Description

The Multiple Student Attendance Management System is a programming-logic project designed to record attendance for multiple students during one session.

The system accepts each student's ID and name, records their attendance status, and calculates the total number of students present and absent.

Aim and Objectives

- Record student identification details.
- Record whether each student is present or absent.
- Count the total number of valid attendance records.
- Calculate the number of students present and absent.
- Display a final attendance summary.

How the System Works

1. The system initializes all attendance counters to zero.
2. The user enters a student's ID and name.
3. The user enters "1" for Present or "0" for Absent.
4. The system updates the appropriate counters.
5. The user chooses whether to record another student.
6. When recording ends, the system displays the final summary.

Attendance Codes

Input| Meaning
1| Present
0| Absent
Other values| Invalid attendance input

Input, Process and Output

Input:

- Student ID
- Student name
- Attendance status
- Continue choice

Process:

- Validate attendance input.
- Update attendance counters.
- Calculate total attendance records.

Output:

- Student attendance status.
- Total students.
- Students present.
- Students absent.

Programming Structures Used

- Sequence: Initializes variables and accepts information.
- Selection: Determines whether a student is present, absent or has invalid attendance input.
- Repetition: Allows multiple student records through a WHILE loop.

Sustainable Development Goal

The project relates to SDG 4 – Quality Education by demonstrating how a digital solution can support organized attendance monitoring in educational institutions.

Limitations

- Student records are not permanently stored.
- Individual student records cannot be searched after entry.
- The continue option currently treats any value other than "1" as a request to stop.

Future Improvements

- Store student records using arrays or a database.
- Display individual student attendance records.
- Improve input validation.
- Generate attendance reports.

Conclusion

The project demonstrates how programming logic can be used to develop a simple attendance management solution using Flowgorithm. It applies sequence, selection and repetition to record multiple students and produce attendance summaries.
